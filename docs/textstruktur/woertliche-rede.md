# Wörtliche Rede (`<sp>`)

```xml
<sp>
  <speaker>Die Kirche spricht</speaker>
  <l>Laßt uns den Glauben predigen und die Innerlichkeit 
     und die Hoffnung aufs Jenseits.</l>
</sp>
<sp>
  <speaker><persName ref="kbga-actors-240">Kutter</persName></speaker>
  <l>Nein, das ists nicht, aber der Kämpfer gegen den 
     Mammon …, der hat Gott.</l>
</sp>
```

Gesprächsverläufe als wörtliche Rede werden mit `<sp>` (speech)
ausgezeichnet. Jeder Redebeitrag enthält einen `<speaker>` und den
gesprochenen Text in `<l>`.

Der Doppelpunkt hinter dem Sprechernamen wird nicht im TEI eingetragen,
sondern über das ODD automatisch eingefügt.

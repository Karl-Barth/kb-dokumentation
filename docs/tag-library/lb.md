# `<lb/>` (Zeilenanfang)

**Modul:** Kernmodule

## Beschreibung

markiert den Anfang einer neuen typographischen 
    Zeile in einer bestimmten Auflage oder Version eines Textes.

!!! note "Ausführliche Dokumentation"

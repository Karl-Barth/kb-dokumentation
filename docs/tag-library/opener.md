# `<opener/>`

**Modul:** Textstruktur

## Beschreibung

fasst Datumszeile, Verfasserangabe, Anredeformel und ähnliche Phrasen zusammen, die einleitend zu
    Beginn eines Abschnitts stehen, vor allem bei einem Brief.

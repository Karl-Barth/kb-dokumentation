# `<graphic/>` (Abbildung)

**Modul:** Kernmodule

## Beschreibung

gibt den Ort einer Bildressource an, 
    die entweder Teil eines Texts oder ein Abbild dessen ist.

!!! note "Ausführliche Dokumentation"
    [Textstruktur > Bilder](https://dokumentation.karl-barth.ch/textstruktur/bilder/)

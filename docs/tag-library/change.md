# `<change/>` (Änderung)

**Modul:** Header

## Beschreibung

Änderungsvermerk in der revisionDesc. Enthält Zeitstempel der letzten Header-Generierung.

## Inhaltsmodell

- *macro.specialPara*

## Attribute

### `@target`

verweist auf ein oder mehrere Elemente, die zu dieser Änderung gehören.

**Datentyp:** `teidata.pointer`

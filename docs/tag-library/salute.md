# `<salute>`
*Grußformel*

enthält eine Anrede oder Grußformel, die einem Vorwort, einer Widmung oder einem anderen
    Abschnitt eines Textes vorangestellt ist oder die Grußformel am Ende eines Briefes, eines
    Vorworts, usw.

# `<epigraph/>` (Motto)

**Modul:** Textstruktur

## Beschreibung

enthält ein anonymes oder jemandem zugeschriebenes Zitat, das am Beginn eines Abschnitts,
    Kapitels oder auf einer Titelseite steht.

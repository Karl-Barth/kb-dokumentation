# `<metamark/>`

**Modul:** Transkription

## Beschreibung

contains or describes any kind of graphic or written signal
   within a document the function of which is to determine how it
   should be read rather than forming part of the actual content of
   the document.

## Inhaltsmodell

- *macro.specialPara*

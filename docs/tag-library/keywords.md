# `<keywords>`
*Schlagwörter*

enthält eine Zusammenstellung von Schlagwörtern oder Phrasen zur Art oder Thematik des Textes.

**Modul:** header

## Attribute

| Attribut | Beschreibung | Werte |
|----------|-------------|-------|
| `@scheme` | gibt das kontrollierte Vokabular an, in dem die benutzten Schlagwörter 
            definiert sind. Dabei kann das scheme-Attribut auf ein taxonomy-Element oder eine andere Ressource verweisen. | teidata.pointer |

## Content-Model

`<term>`, `<list>`

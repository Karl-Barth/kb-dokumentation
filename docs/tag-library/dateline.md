# `<dateline/>`

**Modul:** Textstruktur

## Beschreibung

enthält kurze Angaben zu Entstehungsort, -datum, -zeit, usw. eines Briefs, Zeitungsartikels oder
    anderen Werks. Diese können als Überschrift oder Nachsatz dem Text voran- bzw. nachgestellt
    werden.

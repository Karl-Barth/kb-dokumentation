# `<sic>`
*Lateinisch für 'auf diese Weise', 'so'*

Markiert die fehlerhafte Stelle in der Druckausgabe (innerhalb von choice/sic/corr). Das @ed gibt die Ausgabe an (typisch: pga).

!!! note "Dokumentation"
